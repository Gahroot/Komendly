A shortcode that shows a "Make free ads from your website" box from Komendly.

== Description ==
Add `[komendly_ads]` to a post or page. Visitors type their website address and Komendly makes them a free pack of Facebook and Instagram ads. Optional: `[komendly_ads partner="your-site"]` labels where visitors came from.

This plugin loads one script from www.komendly.com (the widget itself). It stores nothing in your WordPress database and sets no cookies. The widget is an ordinary form that opens https://www.komendly.com/free-ads.

== External services ==
The widget script is served from https://www.komendly.com/embed/komendly-embed.js and the form submits to https://www.komendly.com/free-ads when a visitor presses the button. Terms: https://www.komendly.com/terms. Privacy: https://www.komendly.com/privacy.
