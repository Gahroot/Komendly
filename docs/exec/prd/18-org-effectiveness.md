# 18. Self-improving organisational effectiveness
Outcome: find duplicate, idle, silent or high-cost systems and owner overload; propose changes, never apply them.
Acceptance: findings are `autoApply: false`; a new system needs problem, evidence, constraint, alternatives considered, kill criteria, owner, measurable outcome; the layer cannot edit its own governance (`canChangeGovernance` owner-only, matrix fingerprint pinned).
Status: met. Production dry-run flags several enabled systems that never produced evidence. Code: `org-effectiveness.ts`, `governance.ts`.
