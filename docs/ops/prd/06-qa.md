# System-wide quality assurance

**Goal:** Stop regressions of business-critical rules cheaply on every deploy and prove the sign-up to payment path works.

**Built:** src/lib/__tests__/invariants.test.ts, kly/test/dockerfile-shared.test.ts, engine/test/dockerfile-shared.test.ts, scripts/funnel-smoke.ts, scripts/canary.ts, docs/ops/qa-canary.md

**Success measures:** Invariant suite green before every deploy; canary pass rate (nightly); escaped defects per month (customer-found vs we-found).

**Operating rules:** call `recordOwnerIntervention(db, kind, note)` (src/lib/ops/qa/owner-intervention.ts) whenever the owner does by hand something the system should have done; never for planned reviews. Run `npx tsx scripts/process-review.ts` weekly (add `--apply` to record `process_finding` events); the card on /admin/ads/ops (`_cards/process-card.tsx`, not yet wired into the page) shows the result.

**Open items:** see docs/ops/security-audit.md and docs/ops/privacy-compliance.md.
