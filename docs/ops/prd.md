# Operations PRD (17 areas)

Master control layer for autonomous operations. One file per area under `docs/ops/prd/` so workers do not collide; machine-readable status in `docs/ops/registry.json` (area -> capabilities -> status; same status vocabulary as `docs/growth-ecosystem/registry.json`). Companion docs: [operating manual](operating-manual.md), [boundaries](boundaries.md), [owner dependencies](owner-dependencies.md), [kill switch](kill-switch.md), [knowledge index](knowledge/README.md).

Method: Hormozi constraint thinking (one constraint at a time), Scaling Roadmap stage awareness (pre-revenue: do not over-build), no new complexity, AI only through the Codex provider. Rule for every area: no promised results; status claims need data, not code.
